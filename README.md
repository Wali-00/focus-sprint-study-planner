# 🎯 Focus Sprint – Personal Study Planner

**Focus Sprint** is a personal productivity and study management application designed to help students build consistent study habits, manage daily learning goals, and track their progress through a streak-based system.

The application combines task management, study timers, alarms, mission tracking, and daily progress monitoring in one place.

---

## 🚀 Key Features

### 1. Daily Study Goals
- **AI / ML:** 3 hours daily (Mandatory)
- **Academic Study:** 1 hour daily (Mandatory)
- **Optional Skill Learning:** 2 hours daily (Choose one active skill)

### 2. Skill Learning Missions

Users can choose from the following skills:

- Java
- Spring Boot
- HTML
- CSS
- JavaScript
- React
- Figma

Once a skill is fully learned, users can mark it as **Mission Complete** to remove it from the active task list.

### 3. Streak Tracking
- Tracks daily study consistency.
- Both mandatory tasks must be completed to earn a daily streak.
- Includes a monthly progress calendar.
- Covers the four-month challenge from November 2026 to February 2027.

### 4. Study Timer & Alarm
- Built-in study timer.
- Automatic alarm when the target study duration is reached.
- Pause and resume functionality.
- Alarm sound testing option.

### 5. Task Reset System
- Reset an individual task.
- Reset all tasks for the current day.
- Preserve previous days' streaks and historical progress.

### 6. One-Hour Cooldown
A cooldown system prevents completing another task immediately after completing a task.

### 7. Data Backup
- Export study progress as a backup.
- Import previously exported backup data.
- Store application data locally in the browser.

## 💻 How to Run the Project

### Option 1: Windows Launcher
1. Download or clone this repository.
2. Extract the project folder.
3. Run `START_FOCUS_SPRINT.bat`.
4. The application will open in your browser.

### Option 2: Direct Browser Access
1. Open the project folder.
2. Double-click `Focus_Sprint_Study_Planner_PC.html`.
3. Open it using Google Chrome or Microsoft Edge.

## 🔒 Data & Privacy

- Study progress is stored locally in the browser.
- No account registration is required.
- Backup export and import are available.
- No cloud synchronization is provided.

**Note:** Timer alarms work while the application remains active in a supported browser. Browser or operating-system restrictions may affect alarm playback.
